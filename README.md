# OHSP Anonymizer

เว็บแอปแปลงข้อมูลรายบุคคลให้เป็นข้อมูลนิรนาม (anonymous / pseudonymous) ก่อนส่งให้ AI วิเคราะห์
ค่าเริ่มต้นรองรับไฟล์ **Data Exchange จาก HDC** และกำหนดฟิลด์เองได้สำหรับไฟล์ Excel / CSV รูปแบบอื่น

> 🔒 ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่มีการส่งข้อมูลออกนอกเครื่อง ใช้งานแบบออฟไลน์ได้

## วิธีใช้งาน

1. เปิดใช้งานออนไลน์ที่ **https://nchotenin-tech.github.io/ohsp-anonymizer/**
   หรือดาวน์โหลด [`dist/anonymizer.html`](dist/anonymizer.html) แล้วดับเบิลคลิกเปิดด้วย Chrome / Edge (ใช้ออฟไลน์ได้)
2. ลากไฟล์ `.xlsx` / `.xls` / `.csv` มาวาง
3. ตรวจและปรับวิธีจัดการรายฟิลด์ แล้วกด **ประมวลผล**
4. ตรวจผล k-anonymity แล้วดาวน์โหลดไฟล์ผลลัพธ์ (.xlsx / .csv)

## ความสามารถ

- **ค่าเริ่มต้นสำหรับ HDC**: ลบ `name`, `lname`, `addr` · แปลง `cid`, `pid`, `seq`, `provider` เป็นรหัสแทน · `birth` → ปี · `check_vhid` → 6 หลัก (ตำบล)
- **`pid` + `hoscode`**: รวมรหัสหน่วยบริการก่อนแปลง เพราะ pid ไม่ซ้ำเฉพาะภายในหน่วยบริการ
- **ตรวจจับฟิลด์อัตโนมัติ** จากชื่อฟิลด์ (ไทย/อังกฤษ) และรูปแบบค่า (เลข 13 หลัก, เบอร์มือถือ)
- **13 วิธีจัดการ**: เก็บไว้, ลบทิ้ง, รหัสแทน (SHA-256 + salt), รหัสเรียงลำดับ, ปกปิดบางส่วน, ตัดเหลือ N หลัก, วันที่→ปี / ปี-เดือน / อายุ, เลื่อนวันที่ ±N วัน (คงที่ต่อคน), ช่วงตัวเลข, ค่าคงที่, ล้างข้อความอิสระ
- **ตรวจ k-anonymity** จากฟิลด์ที่เลือกเป็น QI (quasi-identifier)
- อ่าน CSV ได้ทั้ง UTF-8 และ TIS-620 · แปลงวันที่ พ.ศ. → ค.ศ. · รักษาเลข 0 นำหน้า
- บันทึก / โหลดการตั้งค่าเป็น `.json` เพื่อใช้ซ้ำ
- ส่งออกไฟล์ key (รหัสเดิม ↔ รหัสแทน) แยกต่างหาก

## ⚠ ข้อควรระวัง

- **ไฟล์ key และค่า salt ใช้ย้อนกลับหาตัวบุคคลได้** เก็บไว้ในหน่วยงานเท่านั้น ห้ามส่งพร้อมไฟล์ข้อมูล
- ถ้าต้องการให้รหัสตรงกันข้ามไฟล์หรือข้ามเดือน ต้องใช้ salt เดิม
- ห้าม commit ไฟล์ข้อมูลจริง ไฟล์ key หรือไฟล์ตั้งค่าที่มี salt (`.gitignore` กันไว้แล้ว)
- ควรทบทวนผลก่อนนำไปใช้ทุกครั้งตามแนวทาง PDPA

## สำหรับนักพัฒนา

แก้โค้ดที่ `src/template.html` แล้ว build เป็นไฟล์เดียว (ฝัง SheetJS ไว้ในไฟล์ ใช้งานออฟไลน์ได้)

```bash
npm install
npm run build   # → dist/anonymizer.html
```

ทุกครั้งที่ push ขึ้น `main` GitHub Actions จะ build และ deploy ไปที่ GitHub Pages อัตโนมัติ (`.github/workflows/pages.yml`)
